# Leverage ETFs

Aplikacija za zgodovinsko primerjavo donosov osnovnega indeksa ter simuliranih 2x in 3x vzvodnih različic pri začetni investiciji in rednih mesečnih vložkih.

Podprti indeksi:

- S&P 500
- Nasdaq 100
- Nasdaq Composite
